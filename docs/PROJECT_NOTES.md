# Stack House — Project Notes

## Preserved idea: GK Studio beat-machine / finger-drumming trainer

Saved: 2026-09-08. Idea only; no implementation change.

**Simon Says for beats.** Program a beat or pattern, have the pads flash the rhythm, then let the learner reproduce it by finger-drumming.

- Support MIDI pads, computer-keyboard mappings, and touch pads where appropriate.
- Intended for **GK Studio**, rather than the **Stack House arcade**: complex finger-drumming is awkward as a universal keyboard/mouse/mobile arcade mechanic.

Preserved for future GK Studio design work; this note does not add an arcade feature or implementation requirement to Stack House.
